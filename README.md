# 학돌 세금계산서 저장

전자세금계산서를 읽어 업체명·품명·작성일로 PDF 파일명을 자동 정리해 저장하는 브라우저 확장도구입니다.

Chrome, Whale 등 Chromium 기반 브라우저에서 사용할 수 있습니다.

## 📌 주요 기능

- 전자세금계산서의 업체명 자동 인식
- 품명 자동 인식
- 작성일 자동 인식
- 합계금액 확인
- 사업자번호 저장 및 지원 사이트 자동 입력
- 세금계산서 PDF 저장
- 저장 전 업체명·품명·작성일 직접 수정
- 같은 파일명이 있을 경우 기존 파일을 덮어쓰지 않고 별도 저장

## 🌐 지원 사이트

현재 다음 전자세금계산서 사이트를 중심으로 지원합니다.

- SmileEDI
- eCount ERP
- FreeBill
- SmartBill
- eTradeBill
- 홈택스 전자세금계산서
- Dr.bill

사이트의 화면 구성이나 출력 방식이 변경되면 일부 기능이 정상 작동하지 않을 수 있습니다.

## 📝 파일명 규칙

기본 저장 형식은 다음과 같습니다.

`세금계산서(YYMMDD_업체명_품명).pdf`

예시:

`세금계산서(260831_한국교직원공제회 S2B_물품견적정보 1건).pdf`

작성일을 읽지 못한 경우:

`세금계산서(업체명_품명).pdf`

품목이 여러 개인 경우:

`세금계산서(260831_업체명_복사용지 외).pdf`

## 🚀 사용방법

1. 전자세금계산서 조회 페이지를 엽니다.
2. 브라우저 확장프로그램에서 `학돌 세금계산서 저장`을 실행합니다.
3. 업체명·품명·작성일·합계금액을 확인합니다.
4. 필요한 경우 내용을 직접 수정합니다.
5. `세금계산서 PDF 저장`을 누릅니다.
6. 다운로드 폴더에 자동 생성된 파일명으로 저장된 PDF를 확인합니다.

내용이 제대로 읽히지 않았다면 `다시 읽기`를 눌러주세요.

## 🔢 사업자번호 자동 입력

일부 전자세금계산서 사이트는 문서 열람 전에 사업자번호 확인을 요구합니다.

최초 한 번 사업자번호를 저장하면 지원되는 화면에서 자동 입력을 시도합니다.

- 일반 한 칸 입력 방식
- `000 / 00 / 00000` 형태의 3칸 분리 입력 방식

자동 입력이 지원되지 않는 사이트에서는 직접 입력한 뒤 계산서를 열어주세요.

## 💾 PDF 저장

사이트마다 전자세금계산서를 표시하고 출력하는 방식이 달라 사이트별 처리 방식을 적용합니다.

PDF 저장 시 가능한 경우 계산서 본문을 중심으로 저장하며, 사이트의 메뉴·광고·출력용 버튼 등은 출력에서 제외하도록 처리합니다.

사이트 개편이나 브라우저 정책에 따라 결과가 달라질 수 있습니다.

## 🔒 개인정보 및 데이터 처리

전자세금계산서 내용은 현재 브라우저 탭에서 읽어 파일명 생성과 PDF 저장에 사용합니다.

파일은 사용자의 PC 다운로드 폴더에 저장되며, 세금계산서 내용을 별도의 외부 서버에 저장하기 위한 기능은 포함하지 않습니다.

## 🧩 설치방법

1. ZIP 파일의 압축을 풉니다.
2. Chrome 또는 Whale에서 확장프로그램 관리 페이지를 엽니다.
3. `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 선택합니다.
5. 압축을 푼 폴더를 선택합니다.

업데이트 후에는 확장프로그램 관리 화면에서 다시 로드해 주세요.

사이트 구조 변경으로 자동 인식이 정확하지 않을 수 있으므로 저장 전 업체명·품명·작성일을 확인해 주세요.

# 🧾 학돌 세금계산서 저장

전자세금계산서 화면에서 업체명·품명·작성일을 읽고
`세금계산서(YYMMDD_업체명_품명).pdf` 형식으로 저장하는 Chromium 확장프로그램입니다.

네이버 웨일과 Google Chrome에서 사용할 수 있습니다.

## 주요 기능

- 현재 탭의 전자세금계산서에서 업체명·품명·작성일·합계금액을 읽습니다.
- 최초 한 번 저장한 사업자번호를 조회 화면에 자동 입력할 수 있습니다.
- 사업자번호 입력칸이 `3-2-5`로 나뉜 화면도 지원합니다.
- 품목이 2개 이상이면 첫 품명 뒤에 `외`를 붙입니다.
- 사이트별 화면 구조 차이를 adapter로 보정합니다.
- PDF 저장 시 같은 파일명이 있으면 브라우저의 `uniquify` 방식으로 `(1)`, `(2)`가 붙습니다.
- 작성일을 읽지 못해도 날짜만 생략하고 저장할 수 있습니다.

현재 파일명 예시는 다음과 같습니다.

`세금계산서(260831_테스트상사_복사용지).pdf`

작성일이 없으면:

`세금계산서(테스트상사_복사용지).pdf`

## 설치 방법

### 네이버 웨일

1. ZIP 파일의 압축을 풉니다.
2. 주소창에 `whale://extensions`를 입력합니다.
3. 개발자 모드를 켭니다.
4. **압축해제 된 확장앱 설치**를 선택합니다.
5. `manifest.json`이 있는 폴더를 선택합니다.

### Google Chrome

1. ZIP 파일의 압축을 풉니다.
2. 주소창에 `chrome://extensions`를 입력합니다.
3. 개발자 모드를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
5. `manifest.json`이 있는 폴더를 선택합니다.

## 사용 방법

1. 전자세금계산서 조회 화면을 엽니다.
2. 확장프로그램을 실행합니다.
3. 필요한 경우 사업자번호를 저장하고 자동 확인합니다.
4. 업체명·품명·작성일을 확인합니다.
5. 자동 인식이 틀리면 팝업에서 직접 수정합니다.
6. **세금계산서 PDF 저장**을 누릅니다.

PDF 저장은 현재 사이트를 확인한 뒤 사이트별 출력 보정을 적용하고,
그 외 사이트에서는 일반 `Page.printToPDF` 방식으로 처리합니다.

## 사이트별 보정

현재 코드에는 다음 사이트용 전용 처리 또는 보정 로직이 포함되어 있습니다.

- SmileEDI
- eCount ERP
- FreeBill
- SmartBill
- HomeTax
- eTradeBill

사이트의 HTML 구조가 변경되면 자동 인식 규칙도 수정이 필요할 수 있습니다.
인식 결과는 저장 전에 반드시 확인해주세요.

## 개인정보 처리

- 별도 서버나 회원가입 기능이 없습니다.
- 세금계산서 내용을 외부 서버로 전송하는 네트워크 요청 코드는 사용하지 않습니다.
- 사업자번호는 `chrome.storage.local`에 저장되어 같은 브라우저 프로필에서 자동입력에 사용됩니다.
- PDF는 브라우저의 다운로드 기능으로 사용자의 PC에 저장됩니다.
- 실제 계산서·사업자번호·메일 토큰을 GitHub 저장소의 테스트 데이터로 올리지 않습니다.

## 확장프로그램 권한

`manifest.json`에는 다음 권한이 사용됩니다.

- `activeTab`: 사용자가 연 현재 탭에서만 작업
- `scripting`: 계산서 화면 정보 읽기 및 출력 보정
- `storage`: 사업자번호·출력 방향 등 설정 저장
- `downloads`: PDF 저장 및 파일명 지정
- `debugger`: Chrome DevTools Protocol의 `Page.printToPDF` 사용

사이트별 하위 프레임 접근이 필요한 경우에만 제한된 `host_permissions`를 사용합니다.

## 개발 및 테스트

별도 npm 패키지 설치 없이 Node.js가 있으면 회귀 테스트를 실행할 수 있습니다.

```bash
node tests/regression.cjs
```

현재 테스트는 메타데이터 추출, 사업자번호 자동입력, 사이트별 출력 분기,
PDF 유효성 검사, 파일명 생성 및 다운로드 rename 로직을 확인합니다.

## 참고

- `chrome://`, `whale://` 같은 브라우저 내부 페이지에서는 동작하지 않습니다.
- 개발자도구가 같은 탭에 연결되어 있으면 `debugger` 기반 PDF 저장이 실패할 수 있습니다.
- 학교 PC의 관리 정책에 따라 `debugger` 연결이 제한될 수 있습니다.
- 사이트 구조 변경으로 자동 인식이 어긋날 수 있으므로 저장 전 파일명 정보를 확인해주세요.

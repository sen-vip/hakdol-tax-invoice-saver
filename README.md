# 학돌 세금계산서 저장

전자세금계산서를 읽어 업체명·품명·작성일을 확인하고,
`세금계산서(YYMMDD_업체명_품명).pdf` 형식으로 정리해 저장하는 브라우저 확장도구입니다.

Chrome과 네이버 웨일 등 Chromium 기반 브라우저에서 사용할 수 있습니다.

현재 버전: `v1.8.15`

## 📌 주요 기능

- 업체명·품명·작성일·합계금액 자동 인식
- 저장 전 업체명·품명·작성일 직접 수정
- 사업자번호 저장 및 지원 화면 자동 입력
- `000 / 00 / 00000` 형태의 3칸 사업자번호 입력 지원
- 세금계산서 본문을 우선 찾아 PDF로 저장
- 모든 사이트의 PDF를 A4 세로 기준으로 저장
- 같은 파일명이 있으면 `(1)`, `(2)`를 붙여 덮어쓰기 방지
- 작성일을 읽지 못해도 날짜를 제외하고 저장 가능

## 🌐 지원 사이트

다음 전자세금계산서 사이트를 중심으로 전용 처리를 적용하고 있습니다.

- SmileEDI
- eCount ERP
- FreeBill
- SmartBill
- eTradeBill
- TaxBill365
- 홈택스 전자세금계산서
- Dr.bill

그 밖의 사이트에서도 공통 인식·PDF 저장 방식으로 동작을 시도합니다.

사이트의 화면 구조나 출력 방식이 변경되면 일부 기능이 정상 작동하지 않을 수 있습니다.

## 🚀 설치

### 네이버 웨일

1. ZIP 파일의 압축을 풉니다.
2. 주소창에 `whale://extensions`를 입력합니다.
3. 오른쪽 위의 `개발자 모드`를 켭니다.
4. `압축해제 된 확장앱 설치`를 누릅니다.
5. 압축을 푼 폴더에서 `manifest.json`이 들어 있는 폴더를 선택합니다.

### Google Chrome

1. ZIP 파일의 압축을 풉니다.
2. 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
5. 압축을 푼 폴더에서 `manifest.json`이 들어 있는 폴더를 선택합니다.

업데이트한 뒤에는 확장프로그램 관리 화면에서 다시 로드해 주세요.

## 🧾 사용 방법

1. 처음 한 번만 `사업자번호`에서 사용할 사업자번호를 저장합니다.
2. 전자세금계산서 조회 화면에서 확장프로그램을 엽니다.
3. 업체명·품명·작성일·합계금액을 확인합니다.
4. 자동 인식이 맞지 않으면 값을 직접 수정하거나 `다시 읽기`를 누릅니다.
5. 저장될 파일명을 확인한 뒤 `세금계산서 PDF 저장`을 누릅니다.
6. 다운로드 폴더에서 저장된 PDF를 확인합니다.

## 📝 파일명 규칙

기본 형식:

`세금계산서(YYMMDD_업체명_품명).pdf`

예시:

`세금계산서(260915_테스트상사_복사용지).pdf`

품목이 두 개 이상이면 첫 번째 품명 뒤에 `외`를 붙입니다.

`세금계산서(260915_테스트상사_복사용지 외).pdf`

작성일을 읽지 못한 경우에는 날짜를 제외합니다.

`세금계산서(테스트상사_복사용지).pdf`

## 💾 PDF 저장 방식

- 가능한 경우 공급자·공급받는자·작성일·품목·합계금액이 들어 있는 세금계산서 본문을 우선 찾습니다.
- 계산서 본문만 분리할 수 있는 사이트에서는 메뉴·광고·담당자 정보·전송상태·출력 버튼 같은 부가영역을 제외합니다.
- PDF는 공통적으로 A4 세로 기준으로 저장합니다.
- 사이트 구조상 계산서 본문을 확실하게 찾지 못하면 기존 사이트별 출력 방식으로 안전하게 대체합니다.
- 빈 PDF로 의심되는 결과는 가능한 범위에서 저장하지 않도록 검사합니다.

## 🔢 사업자번호 자동 입력

저장한 사업자번호는 브라우저 내부에 보관합니다.

지원되는 조회 화면에서는 자동 입력과 확인을 시도하며,
한 칸 입력 방식과 `3-2-5`로 나뉜 입력 방식을 지원합니다.

자동 입력은 보조 기능입니다. 자동 입력에 실패해도 수동 입력·다시 읽기·PDF 저장 기능을 계속 사용할 수 있습니다.

## 🔒 개인정보

- 별도 회원가입이나 외부 저장 서버가 없습니다.
- 세금계산서 내용과 저장한 사업자번호를 별도 서버로 전송하는 기능은 포함하지 않습니다.
- PDF는 사용자의 브라우저를 통해 PC 다운로드 폴더에 저장됩니다.

## ⚠️ 알아둘 점

- `chrome://`, `whale://` 같은 브라우저 내부 페이지에서는 작동하지 않습니다.
- PDF 생성 중 브라우저가 현재 탭에 잠깐 연결되었다는 안내가 표시될 수 있습니다.
- 개발자도구가 같은 탭에 열려 있으면 PDF 저장이 실패할 수 있습니다.
- 학교나 기관의 브라우저 관리 정책이 디버거 연결을 제한하면 PDF 생성이 실패할 수 있습니다.
- 사이트 개편으로 자동 인식이 달라질 수 있으므로 저장 전 파일명 정보를 확인해 주세요.

- `manifest.json` — 확장프로그램 설정 및 권한
- `popup.html`, `popup.css`, `popup.js` — 확장프로그램 화면
- `extractor.js` — 세금계산서 정보 공통 추출
- `site-adapters.js` — 사이트별 정보 인식 보강
- `print-adapters.js` — 사이트별 출력 정리
- `background.js` — PDF 생성 및 다운로드
- `pdf-utils.js` — 스크린샷 기반 PDF 생성
- `tests/regression.cjs` — 회귀 테스트
- `CHANGELOG.md` — 버전별 변경 기록

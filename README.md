# 학돌 세금계산서 저장

전자세금계산서 화면에서 업체명·품명·작성일을 읽고,  
알아보기 쉬운 파일명으로 PDF 저장을 도와주는 브라우저 확장도구입니다.

Chrome, 네이버 웨일 등 Chromium 기반 브라우저에서 사용할 수 있습니다.

현재 버전: `v1.8.20`

## 📌 주요 기능

- 전자세금계산서 업체명 자동 인식
- 품명 자동 인식
- 작성일 자동 인식
- 합계금액 확인
- 저장 전 업체명·품명·작성일 직접 수정
- 사업자번호 저장 및 지원 화면 자동 입력
- 한 칸 또는 `3-2-5` 형태의 사업자번호 입력 지원
- 세금계산서 본문을 우선 찾아 PDF 저장
- PDF를 A4 세로 기준으로 저장
- 같은 파일명이 있으면 `(1)`, `(2)`를 붙여 덮어쓰기 방지

품명과 작성일은 읽지 못해도 저장할 수 있습니다.

## 📝 파일명 규칙

기본 형식:

`세금계산서(YYMMDD_업체명_품명).pdf`

예시:

`세금계산서(260920_테스트상사_복사용지).pdf`

품목이 여러 개인 경우:

`세금계산서(260920_테스트상사_복사용지 외).pdf`

품명을 읽지 못한 경우:

`세금계산서(260920_테스트상사).pdf`

작성일을 읽지 못한 경우:

`세금계산서(테스트상사_복사용지).pdf`

작성일과 품명을 모두 읽지 못한 경우:

`세금계산서(테스트상사).pdf`

업체명은 파일 구분을 위해 필수로 사용합니다.

## 🚀 사용 방법

1. 전자세금계산서 조회 화면을 엽니다.
2. 브라우저에서 `학돌 세금계산서 저장` 확장프로그램을 실행합니다.
3. 저장될 파일명을 확인합니다.
4. 문제가 없다면 `세금계산서 PDF 저장`을 누릅니다.
5. 업체명·품명·작성일이 다르면 아래의 `파일명 정보 수정`에서 수정합니다.
6. 정보가 제대로 읽히지 않았다면 `다시 읽기`를 눌러주세요.

## 🔢 사업자번호

일부 전자세금계산서 사이트는 계산서를 열기 전에 사업자번호 확인을 요구합니다.

처음 한 번 사업자번호를 저장하면 지원되는 조회 화면에서 자동 입력과 확인을 시도합니다.

지원 형태:

- `0000000000` 한 칸 입력
- `000 / 00 / 00000` 세 칸 입력

자동 입력이 되지 않아도 직접 입력한 뒤 확장프로그램을 계속 사용할 수 있습니다.

## 🌐 지원 사이트

현재 다음 전자세금계산서 사이트를 중심으로 사이트별 처리를 적용하고 있습니다.

- SmileEDI
- eCount ERP
- FreeBill
- SmartBill
- eTradeBill
- TaxBill365
- 홈택스 전자세금계산서
- Dr.bill

그 밖의 사이트에서도 공통 인식 및 PDF 저장 방식을 시도합니다.

사이트 화면이나 출력 구조가 변경되면 일부 기능이 정상적으로 작동하지 않을 수 있습니다.

## 💾 PDF 저장

가능한 경우 계산서의 다음 내용을 포함한 본문 영역을 찾아 저장합니다.

- 공급자
- 공급받는자
- 작성일
- 공급가액·세액
- 품목
- 합계금액

계산서 본문을 구분할 수 있는 사이트에서는 메뉴, 광고, 담당자 정보, 전송상태, 출력 버튼, 푸터 등 불필요한 영역을 제외하도록 처리합니다.

PDF는 A4 세로 기준으로 저장합니다.

사이트 구조상 계산서 본문을 확실하게 구분할 수 없는 경우에는 사이트별 보조 방식으로 처리합니다.

## 🔒 데이터 처리

세금계산서 정보는 현재 브라우저 탭에서 읽어 파일명 생성과 PDF 저장에 사용합니다.

- 별도 회원가입 없음
- 별도 외부 저장 서버 없음
- 세금계산서 내용을 외부 서버에 저장하는 기능 없음
- PDF는 사용자의 PC 다운로드 폴더에 저장

저장한 사업자번호는 브라우저 내부 저장공간을 사용합니다.

## 🧩 설치 방법

### 네이버 웨일

1. ZIP 파일의 압축을 풉니다.
2. 주소창에 `whale://extensions`를 입력합니다.
3. `개발자 모드`를 켭니다.
4. `압축해제 된 확장앱 설치`를 누릅니다.
5. `manifest.json`이 들어 있는 폴더를 선택합니다.

### Google Chrome

1. ZIP 파일의 압축을 풉니다.
2. 주소창에 `chrome://extensions`를 입력합니다.
3. `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
5. `manifest.json`이 들어 있는 폴더를 선택합니다.

새 버전으로 교체한 뒤에는 확장프로그램 관리 화면에서 `다시 로드`를 눌러주세요.

## ⚠️ 참고사항

- 사이트 개편에 따라 자동 인식이 달라질 수 있습니다.
- 저장 전 `저장될 파일명`을 확인해 주세요.
- 업체명을 읽지 못한 경우 직접 입력해야 저장할 수 있습니다.
- 품명과 작성일은 선택값입니다.
- `chrome://`, `whale://` 같은 브라우저 내부 페이지에서는 사용할 수 없습니다.
- PDF 저장 중 브라우저가 현재 탭에 연결되었다는 안내가 잠시 표시될 수 있습니다.
- 같은 탭에서 개발자도구가 실행 중이면 PDF 저장이 실패할 수 있습니다.
- 학교나 기관의 브라우저 보안정책에 따라 PDF 생성이 제한될 수 있습니다.
